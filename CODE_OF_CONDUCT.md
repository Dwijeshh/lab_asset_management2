# Code of Conduct

This project welcomes constructive contributions from people working on laboratory asset management. Be respectful to other contributors and to the MAHE staff whose workflows the application supports.

## Expected behavior

- Discuss ideas and code without personal attacks.
- Give specific, helpful feedback and accept corrections in good faith.
- Respect different backgrounds, experience levels, and perspectives.
- Protect private information about staff, students, and institutions.

Harassment, discriminatory remarks, threats, unwanted personal attention, publishing someone else's private information, and sustained disruption are not acceptable.

## Scope and enforcement

These standards apply to repository issues, pull requests, discussions, reviews, and other project spaces. Maintainers may edit or remove harmful content, warn a participant, or restrict participation when needed. They will consider the context and aim to handle reports fairly.

To report a concern about GitHub content, use the item's **Report content** menu and choose **Report to repository admins** when available. You may also use [GitHub's abuse reporting process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam), especially if the concern involves a maintainer. Do not post sensitive details in a public issue. Reports will be handled as privately as the reporting channel allows.
